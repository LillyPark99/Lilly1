# 공부 위키

중국어·일본어·영어 공부 노트를 날짜·주제별 페이지로 정리한 개인 위키입니다. `index.html`을 브라우저로 열거나 https://lillypark99.github.io/Lilly1/ 에서 볼 수 있습니다.

| 언어 | 원본 노트 | 내용 |
|---|---|---|
| 중국어 | 비즈니스 중국어 노트 | 하루 두 문장, 병음·뜻·문법, 단어장, 문법 모음 |
| 일본어 | 일본어 단어장 | 하루 한자어 3개·가타카나어 2개, 전체 단어 모음 |
| 영어 EC | 영어 EC 공부 노트 | 주제별 단어, 문법 |
| 영어 비즈니스·업무 | 업무 영어 공부 노트 | 업무 단어·표현, 문법 |

원본 노트가 바뀌면 매일 22:00 자동으로 반영되고 커밋됩니다.
