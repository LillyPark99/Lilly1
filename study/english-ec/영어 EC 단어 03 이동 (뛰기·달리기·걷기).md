# 영어 EC 단어 03 이동 (뛰기·달리기·걷기)

| 단어 | 뜻 | 메모 |
|---|---|---|
| jump ★ | 뛰다 / (수치가) 급등하다 | 가장 일반적인 말 |
| leap ★ | 멀리 힘차게 뛰다 / 급증하다 | 과거형 leapt [렙트]. leap at the chance = 기회를 덥석 잡다 |
| hop ★ | 깡충 뛰다 | hop on a call = 잠깐 통화하다 |
| skip ★ | 깡충깡충 뛰다 / 건너뛰다 | 업무에서는 “건너뛰다” 뜻이 많음 |
| vault ★ | 짚고 뛰어넘다 | 명사 vault = 금고 |
| bounce | 튀다, 튀어 오르다 | 이메일이 반송될 때도 bounce |
| run ★ | 달리다 / 운영하다, 돌리다 | run a test = 테스트를 돌리다 |
| jog ★ | 천천히 달리다 | jog one's memory = 기억을 되살리다 |
| dash ★ | 황급히 달려가다 | I have to dash = 급히 가봐야 해요 |
| sprint ★ | 전력 질주하다 | IT에서는 짧은 개발 주기 |
| rush | 서두르다 | 달리지 않아도 씀 |
| stroll | 한가롭게 거닐다 |  |
| wander | 이리저리 돌아다니다 | wonder(궁금해하다)와 철자 주의 |
| march | 행진하다 |  |
| tiptoe | 발끝으로 걷다 |  |
| limp | 절뚝거리다 |  |
