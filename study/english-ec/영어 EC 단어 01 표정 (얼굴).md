# 영어 EC 단어 01 표정 (얼굴)

| 단어 | 뜻 | 메모 |
|---|---|---|
| frown ★ | 얼굴을 찌푸리다, 인상 쓰다 | frown on/upon = 못마땅하게 여기다 |
| scowl | 사납게 찌푸리다 | frown보다 화가 강함 |
| furrowed brow / furrowed eyebrows ★ | 찌푸린 미간 | 고민·혼란. 단수 a furrowed eyebrow는 어색함 |
| knit one's brows | 눈살을 찌푸리다 | 문어체 |
| grimace | (고통·불쾌로) 얼굴을 일그러뜨리다 |  |
| purse one's lips ★ | 입술을 오므리다 | 못마땅·고민. 명사 purse = 지갑 |
| pout | 입을 삐죽 내밀다 | 삐침·투정 |
| smirk | 히죽 웃다(비웃듯) | 부정적 |
| beam | 활짝 웃다 | 긍정적 |
| raise an eyebrow ★ | 눈썹을 치켜올리다(놀람·의심) | raise(목적어 O) vs rise(목적어 X) |
| wink ★ | 한쪽 눈을 찡긋하다 | 의도적인 동작 |
| blink | 눈을 깜박이다 | not even blink = 눈 하나 깜짝 안 하다 |
| squint | 눈을 가늘게 뜨다 | 눈부실 때, 자세히 볼 때 |
| glare ★ | 노려보다 | glare at + 대상. 분노 |
| stare | 빤히 보다 | 감정 중립 |
| glance | 흘끗 보다 | 의도적으로 짧게 |
| glimpse | 얼핏 보다 | 우연히 잠깐 |
