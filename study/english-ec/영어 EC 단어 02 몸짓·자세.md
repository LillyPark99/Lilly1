# 영어 EC 단어 02 몸짓·자세

| 단어 | 뜻 | 메모 |
|---|---|---|
| shrug ★ | 어깨를 으쓱하다 | shrug off = 대수롭지 않게 넘기다 |
| tilt one's head ★ | 고개를 갸웃하다 | 명사구 a tilted head. tilted to head X |
| nod | 고개를 끄덕이다 | nod off = 꾸벅꾸벅 졸다 |
| shake one's head | 고개를 가로젓다 | shake hands = 악수하다 |
| bow ★ | 고개 숙여 인사하다 | 발음 [바우]. [보우]는 활·리본 |
| flex ★ | 근육에 힘을 주다 | flex one's muscles = 힘을 과시하다 |
| bend ★ | 굽히다 | 과거형 bent. bend the rules = 규칙을 봐주다 |
| bend over | 허리를 숙이다 | bend over backwards = 무척 애쓰다 |
| extend ★ | 뻗다 / (기한을) 연장하다 | 업무에서는 기한·계약 연장 뜻이 더 많음 |
| stretch | 몸을 죽 펴다 | stretch the budget = 예산을 빠듯하게 쓰다 |
