# 영어 EC 단어 14 집·건물 종류 (types of buildings)

> 원본 문서에서 자동으로 만든 페이지입니다. 내용은 원본에서 고치면 다음 동기화 때 반영됩니다.

- 원본 제목: 14. 집·건물 종류 (types of buildings)

| 단어 | 뜻 | 메모 |
|---|---|---|
| loft (room) ★ | 로프트, 다락방 | 층고가 높고 트인 공간 또는 복층 위쪽 공간. 보통 a loft 또는 a loft apartment라고 함 |
| mansion ★ | 대저택 | 한국의 “맨션”(중소형 공동주택)과 다름 주의 |
| apartment complex ★ | 아파트 단지 | 아파트 한 채는 an apartment building |
| studio (apartment) ★ | 원룸 | 영국에서는 studio flat |
| duplex ★ | 복층 집 / 2가구 주택 | 미국에서는 한 건물을 두 가구가 나눠 쓰는 집을 뜻하기도 함 |
| cottage ★ | 시골의 작은 집 | 아늑한 전원주택 느낌 |
| detached house | 단독주택 | single-family home이라고도 함 |
| townhouse | 타운하우스 | 벽을 맞대고 줄지어 있는 여러 층 집 |
| condominium (condo) | 분양 아파트 | 소유하는 아파트. 아파트(apartment)는 보통 임대 |
| penthouse | 펜트하우스 | 꼭대기 층의 고급 집 |
| bungalow | 단층집 |  |
| villa | 별장, 큰 전원주택 | 한국의 “빌라”와 다름 주의 |
| cabin | 오두막 | 산·호수 근처 나무집 |
