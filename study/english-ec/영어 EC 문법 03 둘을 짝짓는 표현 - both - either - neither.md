# 영어 EC 문법 03 둘을 짝짓는 표현 - both / either / neither

> 원본 문서에서 자동으로 만든 페이지입니다. 내용은 원본에서 고치면 다음 동기화 때 반영됩니다.

- 원본 제목: 3. 둘을 짝짓는 표현: both / either / neither

| 문법 | 형태·규칙 | 예문 |
|---|---|---|
| both A and B | A와 B 둘 다. 복수 동사 | Both the merchant and the PSP have agreed. (가맹점과 PSP 모두 동의했다.) |
| either A or B ★ | 둘 중 하나. 동사는 가까운 B에 맞춤 | Either you or your manager needs to sign the form. (귀하나 매니저님 중 한 분이 서명해야 합니다.) |
| neither A nor B ★ | 둘 다 아님. 동사는 B에. neither ~ or X, not을 또 쓰지 않음 | Neither the merchant nor the PSPs have replied. (가맹점도 PSP들도 답이 없다.) |
| not only A but (also) B | A뿐 아니라 B도. 동사는 B에 | Not only the fee but also the settlement cycle has changed. (수수료뿐 아니라 정산 주기도 바뀌었다.) |
| either / neither + 단수 명사 ★ | 단수 명사 + 단수 동사. 셋 이상이면 any / none | Neither option works for us. (두 안 모두 저희에게는 맞지 않습니다.) |
| 긍정 맞장구: too / so | 긍정문에 “나도”: I can too. / So can I. (So 뒤 어순 도치) | A: I can join the call. B: So can I. (A: 저 통화 들어갈 수 있어요. B: 저도요.) |
| 부정 맞장구: either / neither ★ | 부정문에 “나도”: I can't either. / Neither can I. too X | A: I can't join the call. B: Neither can I. (A: 저 통화 못 들어가요. B: 저도요.) |
