# 영어 EC 문법 01 가정법·후회·아쉬움

> 원본 문서에서 자동으로 만든 페이지입니다. 내용은 원본에서 고치면 다음 동기화 때 반영됩니다.

- 원본 제목: 1. 가정법·후회·아쉬움

| 문법 | 형태·규칙 | 예문 |
|---|---|---|
| 가정법 과거 | If + 과거형, would + 동사원형 (지금 사실의 반대) | If I had more time, I would review the contract again. (시간이 더 있다면 계약서를 다시 검토할 텐데.) |
| 가정법 과거완료 ★ | If + 주어 + had p.p., would have p.p. (과거 사실의 반대). if절에 would X, 주어 빠뜨리지 않기 | If we had known about the fee, we would have told you. (그 수수료를 알았더라면 말씀드렸을 겁니다.) |
| 혼합 가정법 ★ | If + had p.p., would + 동사원형 (그때 안 한 일 → 지금 결과) | If I had gone to graduate school, my salary would be much higher now. (대학원에 갔더라면 지금 월급이 훨씬 높을 텐데.) |
| should have p.p. | ~했어야 했는데 (후회). should of X | We should have checked the tax issue earlier. (세금 문제를 더 일찍 확인했어야 했다.) |
| with hindsight ★ | 지나고 보니 + 주로 should have p.p. in hindsight가 더 흔함 | With hindsight, we should have signed the contract earlier. (지나고 보니 계약을 더 일찍 했어야 했다.) |
| if only ★ | If only + 과거형(지금 아쉬움) / had p.p.(과거 후회). 현재형 X | If only we had known about the regulation sooner. (규제를 더 빨리 알았더라면 좋았을 텐데.) |
| I wish | if only와 구조가 같고 감정은 덜 강함. be동사는 were | I wish I were in Tokyo for the meeting. (회의 때문에 도쿄에 있으면 좋을 텐데.) |
| it's a real shame ★ | It's a shame (that) + 절 / to + 동사. shame은 “수치”가 아니라 “아쉬움” | It's a real shame you can't join the meeting. (회의에 못 오신다니 정말 아쉽네요.) |
