# 중국어 문법 모음

Day 페이지의 문법 설명을 순서대로 모았습니다.

## [[중국어 Day 01]]

- 安排(ānpái) + 일정/활동: "~을 잡다, 준비하다". (安排时间(ānpái shíjiān), 安排见面(ānpái jiànmiàn))
- 一次(yí cì): 동작의 횟수를 나타내는 양사, "한 번".
- 주제 먼저 말하기: 这个问题(zhège wèntí)를 문장 맨 앞에 두는 회화체 구조.
- 동사 + 一下(yíxià): "좀 ~해 보다", 말투를 부드럽게 함. (看一下(kàn yíxià), 查一下(chá yíxià))
- 给(gěi) + 사람 + 回复(huífù): "~에게 회신하다", 给您(gěi nín)은 공손한 표현.

## [[중국어 Day 02]]

- 请问(qǐngwèn) + 질문: "실례지만, 여쭤보겠습니다". 질문을 정중하게 시작하는 표현.
- 笔(bǐ): 거래·금액·자금을 세는 양사. (一笔钱(yì bǐ qián), 这笔订单(zhè bǐ dìngdān))
- 到账(dàozhàng): "(돈이) 계좌에 들어오다, 입금되다". 能(néng)과 함께 "입금될 수 있다"로 씀.
- 동사 + 后的(hòu de) + 명사: "~한 후의 ~". (修改后的版本(xiūgǎi hòu de bǎnběn), 签字后的合同(qiānzì hòu de hétong))
- 麻烦您(máfan nín) + 동사: "번거로우시겠지만 ~해 주세요". 请(qǐng)보다 부드러운 부탁 표현.
- 看一下(kàn yíxià): Day 1의 동사 + 一下(yíxià) 복습, "좀 봐 주세요".

## [[중국어 Day 03]]

- 동사 + 得(de) + 怎么样(zěnmeyàng): "~한 게 어때요?" 정도보어로 상태·결과를 물음. (睡得怎么样(shuì de zěnmeyàng), 吃得怎么样(chī de zěnmeyàng))
- 过(guò): 여기서는 "(시간을) 보내다". (过周末(guò zhōumò), 过生日(guò shēngrì))
- 一整天(yì zhěng tiān): "하루 종일". 시간을 나타내는 말이 동사 + 了(le) 뒤에 와서 지속 시간을 나타냄.
- 越来越(yuè lái yuè) + 형용사: "점점 ~해지다". 문장 끝 了(le)와 함께 변화를 나타냄. (越来越忙(yuè lái yuè máng))
- ……的时候(de shíhou): "~할 때". (吃饭的时候(chīfàn de shíhou))
- 多(duō) + 동사 + 点儿(diǎnr): "좀 더 ~하다". 권유할 때 자주 씀. (多吃点儿(duō chī diǎnr), 多喝点儿水(duō hē diǎnr shuǐ))

## [[중국어 Day 04]]

- 刚(gāng) + 동사: "막 ~했다". 방금 일어난 일을 나타냄. (刚起床(gāng qǐchuáng), 刚下班(gāng xiàbān))
- 快(kuài) + 동사/형용사 + 了(le): "곧 ~하게 되다". 임박한 상황을 나타냄. (快到了(kuài dào le), 快下雨了(kuài xiàyǔ le))
- 等(děng) + A + 再(zài) + B: "A하고 나서 B하다". 순서를 정해 미룰 때 씀. (等你回来再说(děng nǐ huílai zài shuō))
- 동사 + 好(hǎo): 결과보어, "(제대로) 다 ~하다". 充好电(chōng hǎo diàn), 准备好(zhǔnbèi hǎo)
- A是A，就是……: "A하긴 A한데, 다만 ~". 일단 인정하고 아쉬운 점을 덧붙이는 회화 표현. (便宜是便宜，就是有点儿远(piányi shì piányi, jiùshì yǒudiǎnr yuǎn))
- 就是(jiùshì): 여기서는 "다만, 단지". 앞 내용에 대한 아쉬움·단점을 말할 때 씀.
- 家(jiā): 가게·회사·식당을 세는 양사. (一家咖啡店(yì jiā kāfēidiàn))
- 太(tài) + 형용사 + 了(le): "너무 ~하다". 정도가 지나침을 나타냄.

## [[중국어 Day 05]]

- 本来(běnlái) + 打算(dǎsuàn): "원래 ~하려고 했다". 계획이 바뀌었음을 미리 알려 줌. (我本来想去(wǒ běnlái xiǎng qù))
- 结果(jiéguǒ): 문장 중간에서 "그런데 결국, 결과적으로". 예상과 다른 결과를 이어 줌. (结果下雨了(jiéguǒ xiàyǔ le))
- 只好(zhǐhǎo) + 동사: "어쩔 수 없이 ~하다". 다른 선택지가 없을 때 씀. (只好打车(zhǐhǎo dǎchē))
- 改天(gǎitiān): "다음에, 다른 날에". 약속을 미룰 때 자주 씀. (改天再聊(gǎitiān zài liáo))
- 要是(yàoshi)……的话(dehuà): "만약 ~라면". 如果(rúguǒ)보다 회화에서 더 자주 씀. (要是下雨的话(yàoshi xiàyǔ dehuà))
- 咱们(zánmen): 듣는 사람을 포함한 "우리". 我们(wǒmen)보다 친근한 말투.
- 동사 중첩 逛逛(guàngguang): "좀 ~해 보다". 가볍고 편한 느낌을 줌. 이합사는 앞 글자만 겹침. (散散步(sàn san bù), 聊聊天(liáo liao tiān))
- 문장 끝 吧(ba): "~하자". 제안·권유를 나타냄. (走吧(zǒu ba))

## [[중국어 Day 06]]

- 差点儿(chàdiǎnr) + 동사: "하마터면 ~할 뻔했다". 실제로는 일어나지 않은 일을 말함. (差点儿迟到(chàdiǎnr chídào), 差点儿摔倒(chàdiǎnr shuāidǎo))
- 把(bǎ) + 목적어 + 동사 + 在(zài) + 장소: "~을 ~에 (두다/놓다)". 물건을 어디에 두었는지 말할 때 씀. (把包放在桌子上(bǎ bāo fàng zài zhuōzi shang))
- 幸亏(xìngkuī): "다행히, ~덕분에". 나쁜 일을 피할 수 있었던 이유를 말할 때 씀. (幸亏你来了(xìngkuī nǐ lái le))
- 一(yī)……就(jiù)……: "~하기만 하면 (곧) ~하다". 조건과 결과가 바로 이어짐. (一下雨就堵车(yí xiàyǔ jiù dǔchē), 一喝酒就脸红(yì hē jiǔ jiù liǎnhóng))
- 连(lián) + 명사 + 都(dōu)/也(yě) + 동사: "~조차도, ~마저". 극단적인 예를 들어 강조함. (连水都没喝(lián shuǐ dōu méi hē))
- 睡懒觉(shuì lǎnjiào): "늦잠 자다". 睡觉(shuìjiào)처럼 이합사라서 사이에 수식어가 들어감. (睡了个懒觉(shuì le ge lǎnjiào))

## [[중국어 Day 07]]

- ……的路上(de lùshang): "~하는 길에". 이동 중에 무언가를 할 때 씀. (上班的路上(shàngbān de lùshang), 回家的路上(huí jiā de lùshang))
- 顺便(shùnbiàn) + 동사: "~하는 김에". 원래 하던 일에 다른 일을 덧붙일 때 씀. (顺便去趟超市(shùnbiàn qù tàng chāoshì))
- 帮(bāng) + 사람 + 동사: "~에게 ~해 주다". 부탁할 때 아주 자주 씀. (帮我看看(bāng wǒ kànkan), 帮我拿着(bāng wǒ ná zhe))
- 一(yī) + 양사 + 都(dōu) + 没有(méiyǒu): "하나도 없다". 강한 부정을 나타냄. (一个人都没有(yí ge rén dōu méiyǒu), 一分钱都没有(yì fēn qián dōu méiyǒu))
- 买瓶牛奶(mǎi píng niúnǎi): 회화에서는 동사 뒤 수사 一(yī)를 자주 생략함. (喝杯咖啡(hē bēi kāfēi))
- 동사 + 不下去(bu xiàqù): 가능보어 부정형, "(더 이상) 계속 ~할 수 없다". 긍정은 看得下去(kàn de xiàqù). (听不下去(tīng bu xiàqù), 吃不下去(chī bu xiàqù))
- 还是(háishi) + 别(bié) + 동사 + 了(le): "~하지 않는 게 낫겠다". 상대에게 조언할 때 씀. (你还是早点儿睡吧(nǐ háishi zǎo diǎnr shuì ba))
- 了一半就(le yíbàn jiù): "반만 ~하고 바로". 就(jiù)가 예상보다 일찍 멈췄다는 느낌을 줌.
- 部(bù): 영화·드라마를 세는 양사. (一部电影(yí bù diànyǐng))

## [[중국어 Day 08]]

- 估计(gūjì) + 문장: "아마 ~일 것 같다". 회화에서 추측할 때 아주 자주 씀. (估计他不来了(gūjì tā bù lái le))
- 还得(hái děi) + 동사: "아직 더 ~해야 한다". 이때 得는 děi로 읽음. (还得等一会儿(hái děi děng yíhuìr))
- 才(cái) + 동사: "그제야, 겨우 ~하다". 예상보다 늦거나 오래 걸림을 나타냄. 就(jiù)와 반대 느낌. (他十点才起床(tā shí diǎn cái qǐchuáng))
- A了(le)就(jiù)B: "A하면 (바로) B해". 조건이 생기면 그렇게 하라는 가벼운 권유. (累了就休息(lèi le jiù xiūxi))
- 迷上(míshàng) + 대상: "~에 푹 빠지다". 방향보어 上(shàng)이 "~하기 시작해 붙다"의 뜻. (爱上(àishàng), 喜欢上(xǐhuan shàng))
- 不管(bùguǎn) + 多(duō) + 형용사, ……都(dōu)……: "아무리 ~해도 ~한다". 조건에 상관없이 결과가 같음. (不管多忙，都要吃早饭(bùguǎn duō máng, dōu yào chī zǎofàn))
- 要(yào) + 동사: 여기서는 "꼭 ~하려고 한다". 의지·습관을 나타냄.
- 顿(dùn): 끼니를 세는 양사. (吃一顿饭(chī yí dùn fàn), 请你吃顿饭(qǐng nǐ chī dùn fàn))

## [[중국어 Day 09]]

- 怎么(zěnme) + 也(yě) + 부정: "아무리 해도 ~이 안 되다". 노력해도 안 될 때 씀. (怎么也找不到(zěnme yě zhǎo bu dào), 怎么也想不起来(zěnme yě xiǎng bu qǐlái))
- 睡不着(shuì bu zháo): 결과보어 着(zháo) "(목적을) 이루다"의 가능보어 부정형, "잠들 수 없다". 긍정은 睡得着(shuì de zháo). (买不着(mǎi bu zháo), 找不着(zhǎo bu zháo))
- 干脆(gāncuì) + 동사: "아예, 차라리 (시원하게) ~하다". 고민하다가 결단을 내릴 때 씀. (干脆打车吧(gāncuì dǎchē ba), 干脆不去了(gāncuì bú qù le))
- 동사 + 了(le) + (一)会儿(huìr) + 목적어: "잠깐 ~했다". 시량보어는 동사와 목적어 사이에 옴. (聊了会儿天(liáo le huìr tiān), 玩了会儿手机(wán le huìr shǒujī))
- 동사 + 着(zhe) + 형용사: "~해 보니 ~하다". 직접 해 본 느낌을 말할 때 씀. (听着不错(tīng zhe búcuò), 看着挺好吃(kàn zhe tǐng hǎochī))
- 有点儿(yǒudiǎnr) + 형용사: "좀 ~하다". 주로 불만·아쉬움 등 부정적인 느낌. 一点儿(yìdiǎnr)은 형용사 뒤에 옴. (有点儿贵(yǒudiǎnr guì) ↔ 便宜一点儿(piányi yìdiǎnr))
- 能不能(néng bu néng) + 동사: 정반의문문, "~할 수 있어요?" 부탁을 부드럽게 함. (能不能便宜点儿(néng bu néng piányi diǎnr))
- 형용사 + 一号(yí hào): "한 치수 ~한". 小一号(xiǎo yí hào) "한 치수 작은", 大一号(dà yí hào) "한 치수 큰". 的(de)로 끝나 "~한 것"을 나타냄.

## [[중국어 Day 10]]

- 早知道(zǎo zhīdào)……，就(jiù)……了(le): "진작 ~인 줄 알았으면 ~했을 텐데". 이미 지난 일을 후회할 때 씀. (早知道你也去，我就等你了(zǎo zhīdào nǐ yě qù, wǒ jiù děng nǐ le))
- 这么(zhème) + 형용사: "이렇게 ~하다". 예상보다 정도가 심할 때 씀. (这么贵(zhème guì), 这么晚(zhème wǎn))
- 堵(dǔ): "(길이) 막히다". 회화에서는 堵车(dǔchē)로도 자주 씀. (路上很堵(lùshang hěn dǔ))
- 坐(zuò) + 교통수단 + 来/去(lái/qù): "~을 타고 오다/가다". 수단을 먼저, 이동 동사를 뒤에 씀. (坐公交去(zuò gōngjiāo qù), 坐飞机来(zuò fēijī lái))
- 수식어 + 的(de) + 那(nà) + 양사 + 명사: "~한 그 ~". 긴 수식어로 대상을 특정함. (你说的那本书(nǐ shuō de nà běn shū), 昨天见的那个人(zuótiān jiàn de nà ge rén))
- 동사 + 过(guo): "~해 본 적 있다". 경험을 나타냄. 부정은 没(méi) + 동사 + 过(guo). (我吃过(wǒ chī guo), 没去过(méi qù guo))
- 确实(quèshí): "확실히, 정말로". 상대 말이나 소문이 맞다고 인정할 때 씀. (确实挺好(quèshí tǐng hǎo))
- 难怪(nánguài): "어쩐지, 그러니까 ~했구나". 이유를 알고 나서 납득할 때 씀. (难怪这么便宜(nánguài zhème piányi), 难怪他不高兴(nánguài tā bù gāoxìng))

## [[중국어 Day 11]]

- 先别(xiān bié) + 동사: "일단 ~하지 마". 상대의 행동을 잠깐 멈추게 할 때 씀. (先别走(xiān bié zǒu), 先别告诉他(xiān bié gàosu tā))
- 急着(jízhe) + 동사: "서둘러 ~하려 하다, 급하게 ~하다". 别(bié)와 함께 "서두르지 마"로 자주 씀. (急着回家(jízhe huí jiā), 别急着做决定(bié jízhe zuò juédìng))
- 동사 + 完(wán): 결과보어, "다 ~하다, ~을 끝내다". 부정은 没(méi) + 동사 + 完(wán). (吃完了(chī wán le), 还没看完(hái méi kàn wán))
- 还(hái)……呢(ne): "아직 ~한 상태야". 상황이 계속되고 있음을 부드럽게 강조함. (他还在睡觉呢(tā hái zài shuìjiào ne), 我还没吃饭呢(wǒ hái méi chī fàn ne))
- 除了(chúle)……以外(yǐwài)，都(dōu)……: "~을 빼고 모두 ~". 뒤에 也(yě)/还(hái)가 오면 "~외에도 또"라는 뜻이 됨. (除了他以外，大家都来了(chúle tā yǐwài, dàjiā dōu lái le) / 除了咖啡，我也喜欢喝茶(chúle kāfēi, wǒ yě xǐhuan hē chá))
- 行(xíng): "괜찮다, 된다". 약속·제안에 동의할 때 짧게 씀. (明天也行(míngtiān yě xíng), 这样行不行?(zhèyàng xíng bu xíng))
- 你看(nǐ kàn) + 질문: "네 생각엔 ~?" 상대의 의견을 물을 때 씀. 여기서 看(kàn)은 "보다"가 아니라 "판단하다". (你看怎么样?(nǐ kàn zěnmeyàng))
- 方便(fāngbiàn): "(시간·형편이) 괜찮다, 편하다". 약속 잡을 때 상대 사정을 배려하는 표현. (你什么时候方便?(nǐ shénme shíhou fāngbiàn))

## [[중국어 Day 12]]

- 好久没(hǎojiǔ méi) + 동사 + 了(le): "오랫동안 ~ 안 했다". 한동안 하지 않은 일을 말할 때 씀. (好久没见了(hǎojiǔ méi jiàn le), 好久没运动了(hǎojiǔ méi yùndòng le))
- 형용사 + 得不行(de bùxíng): "엄청 ~하다, ~해서 못 견디겠다". 정도가 아주 심함을 나타내는 회화체 정도보어. (累得不行(lèi de bùxíng), 饿得不行(è de bùxíng))
- 非得(fēiděi)……不可(bùkě): "꼭 ~해야만 한다". 강한 필요나 결심을 나타냄. 회화에서는 不可(bùkě)를 생략하기도 함. (今天非得做完不可(jīntiān fēiděi zuò wán bùkě))
- 好好(hǎohǎo) + 동사: "제대로, 푹 ~하다". (好好休息(hǎohǎo xiūxi), 好好想想(hǎohǎo xiǎngxiang))
- 正要(zhèng yào) + 동사: "막 ~하려던 참이다". 그때 다른 일이 끼어들었음을 말할 때 씀. (我正要给你打电话(wǒ zhèng yào gěi nǐ dǎ diànhuà))
- 동사 + 起(qǐ) + 목적어 + 来(lái): "~하기 시작하다". 목적어는 起(qǐ)와 来(lái) 사이에 옴. (唱起歌来(chàng qǐ gē lái), 聊起天来(liáo qǐ tiān lái))
- 看来(kànlái): "보아하니 ~인 것 같다". 눈앞의 상황을 근거로 판단할 때 씀. 估计(gūjì)보다 근거가 분명한 느낌. (看来他不会来了(kànlái tā bú huì lái le))
- 只能(zhǐ néng) + 동사 + 了(le): "~할 수밖에 없다". (只能等了(zhǐ néng děng le))
- 待着(dāi zhe): "(한곳에) 머물러 있다". 待(dāi)는 회화에서 "있다, 머무르다"의 뜻. (在家待着(zài jiā dāi zhe), 待了一会儿(dāi le yíhuìr))

## [[중국어 Day 13]]

- 被(bèi) + 행위자 + 동사 + 기타 성분: 피동문, "~에게 ~당하다". 주로 원하지 않은 일에 씀. 동사 뒤에 了(le)나 결과보어가 붙음. (我的蛋糕被弟弟吃了(wǒ de dàngāo bèi dìdi chī le), 钱包被偷了(qiánbāo bèi tōu le))
- 동사 + 错(cuò): 결과보어, "잘못 ~하다". (走错路(zǒu cuò lù), 打错电话(dǎ cuò diànhuà), 听错了(tīng cuò le))
- 害得(hài de) + 사람 + 결과: "~하는 바람에 (누가) ~하게 됐다". 남 탓을 하며 나쁜 결과를 말할 때 씀. (你迟到了，害得我们等了半天(nǐ chídào le, hài de wǒmen děng le bàntiān))
- 동사 + 了(le) + 半天(bàntiān): "한참 동안 ~했다". 실제 반나절이 아니라 "오래"라는 과장 표현. (说了半天(shuō le bàntiān), 想了半天(xiǎng le bàntiān))
- 既然(jìrán)……，那(nà)/就(jiù)……: "기왕 ~한 이상, ~하자". 이미 사실인 것을 근거로 제안·결론을 낼 때 씀. (既然来了，就多玩儿几天吧(jìrán lái le, jiù duō wánr jǐ tiān ba))
- 不用(búyòng) + 동사: "~할 필요 없다, ~안 해도 된다". 不要(búyào) "~하지 마"와 구별. (不用谢(búyòng xiè), 明天不用早起(míngtiān búyòng zǎo qǐ))
- 陪(péi) + 사람 + 동사: "~와 함께 ~해 주다". 상대 곁에 있어 주는 느낌. (陪我去医院(péi wǒ qù yīyuàn), 陪孩子玩儿(péi háizi wánr))
- 场(chǎng): 영화 상영·경기·공연 등 한 회를 세는 양사. 작품 자체를 셀 때는 部(bù). (看场电影(kàn chǎng diànyǐng), 一场比赛(yì chǎng bǐsài))
- 문장 끝 呗(bei): "~하면 되지, ~하자". 吧(ba)보다 더 가볍고 편한 말투로, 당연하다는 느낌을 줌. (不会就问呗(bú huì jiù wèn bei))

## [[중국어 Day 14]]

- 光顾着(guāng gùzhe) + 동사: "~하는 데만 정신이 팔려서". 그 바람에 다른 걸 놓쳤다는 뉘앙스. (光顾着说话(guāng gùzhe shuōhuà), 光顾着玩儿，忘了吃饭(guāng gùzhe wánr, wàng le chīfàn))
- 一不小心(yí bù xiǎoxīn): "깜빡하는 사이에, 실수로". 의도치 않게 생긴 일 앞에 씀. (一不小心摔倒了(yí bù xiǎoxīn shuāidǎo le), 一不小心说漏嘴了(yí bù xiǎoxīn shuō lòu zuǐ le))
- 동사 + 过(guò): 방향보어, "(지점을) 지나치다". 경험의 过(guo)와 달리 4성으로 읽음. (坐过站(zuò guò zhàn), 睡过头了(shuì guò tóu le), 走过头了(zǒu guò tóu le))
- 站(zhàn): 정거장 수를 세는 양사. (还有三站(hái yǒu sān zhàn), 下一站(xià yí zhàn))
- 형용사 + 得厉害(de lìhai): "몹시 ~하다". 정도가 심함을 나타내며, 주로 좋지 않은 상태에 씀. (疼得厉害(téng de lìhai), 堵得厉害(dǔ de lìhai))
- 동사 + 양사 + 명사: 수사 一(yī)를 생략한 회화체. 带把伞(dài bǎ sǎn)의 把(bǎ)는 손잡이 있는 물건을 세는 양사로, 把자문의 把와 다름. (买瓶水(mǎi píng shuǐ), 一把椅子(yì bǎ yǐzi))
- 万一(wànyī): "만에 하나, 혹시라도". 일어나지 않았으면 하는 일을 가정할 때 씀. (万一迟到了怎么办(wànyī chídào le zěnme bàn))
- ……也不怕(yě bú pà): "~해도 걱정 없다". 미리 대비해 두었다는 느낌. (有了地图，迷路也不怕(yǒu le dìtú, mílù yě bú pà))

## [[중국어 Day 15]]

- A + 比(bǐ) + B + 형용사 + 多了(duō le): "A가 B보다 훨씬 ~하다". 차이가 클 때 형용사 뒤에 多了(duō le)를 붙임. 比(bǐ) 비교문에는 很(hěn)·非常(fēicháng)을 쓰지 않음. (今天比昨天冷多了(jīntiān bǐ zuótiān lěng duō le), 这个比那个便宜多了(zhège bǐ nàge piányi duō le))
- 比我想象的(bǐ wǒ xiǎngxiàng de): "내가 생각한 것보다, 생각보다". 比想象中(bǐ xiǎngxiàng zhōng)이라고도 함. (比我想象的难(bǐ wǒ xiǎngxiàng de nán))
- 带(dài) + 사람 + 来/去(lái/qù) + 동사: "~을 데리고 와서/가서 ~하다". 물건뿐 아니라 사람을 데려갈 때도 带(dài)를 씀. (带孩子去公园玩儿(dài háizi qù gōngyuán wánr), 带你去看看(dài nǐ qù kànkan))
- 尝尝(chángchang): 동사 중첩 복습, "좀 맛보다". 음식을 권할 때 아주 자주 씀. (你尝尝这个(nǐ chángchang zhège))
- 一边(yìbiān) + A + 一边(yìbiān) + B: "A하면서 B하다". 두 동작을 동시에 할 때 씀. 회화에서는 边(biān)……边(biān)……로 줄이기도 함. (一边吃饭一边看手机(yìbiān chī fàn yìbiān kàn shǒujī), 边走边聊(biān zǒu biān liáo))
- 不知不觉(bù zhī bù jué): "나도 모르는 사이에, 어느새". 시간이 빨리 지나갔거나 변화를 늦게 알아챘을 때 씀. (不知不觉一年过去了(bù zhī bù jué yì nián guòqu le))
- 就(jiù) + 到(dào) + 시간 + 了(le): "벌써 ~(시간)이 되다". 就(jiù)가 "생각보다 빨리"라는 느낌을 더함. (才(cái)와 반대) (一会儿就到十点了(yíhuìr jiù dào shí diǎn le))

## [[중국어 Day 16]]

- 의문사 + 也/都(yě/dōu) + 부정: "아무 ~도 …하지 않다". 哪儿(nǎr)·谁(shéi)·什么(shénme) 같은 의문사가 '모든 것'을 가리킴. (谁都不认识(shéi dōu bú rènshi), 什么也没吃(shénme yě méi chī))
- 就(jiù) + 想(xiǎng) + 동사: 여기서 就(jiù)는 "그냥, 오직". 다른 건 말고 이것만 하고 싶다는 느낌. (我就想睡觉(wǒ jiù xiǎng shuìjiào))
- 동사1 + 着(zhe) + 동사2: "~한 채로 ~하다". 동사1이 동사2를 하는 방식·자세를 나타냄. (躺着看手机(tǎngzhe kàn shǒujī), 站着吃饭(zhànzhe chī fàn))
- 追剧(zhuī jù): "드라마를 챙겨 보다, 정주행하다". 회화에서 아주 자주 쓰는 표현. (最近在追什么剧?(zuìjìn zài zhuī shénme jù?))
- 还以为(hái yǐwéi)……呢(ne): "(사실과 달리) ~인 줄 알았다". 以为(yǐwéi)는 생각이 틀렸을 때 씀. 자기 의견을 말할 땐 认为(rènwéi)/觉得(juéde). (我还以为你不来了呢(wǒ hái yǐwéi nǐ bù lái le ne))
- 原来(yuánlái): "알고 보니". 몰랐던 사실을 새로 알게 됐을 때 문장 앞에 씀. (原来是你啊(yuánlái shì nǐ a))
- 早就(zǎo jiù)……了(le): "진작, 이미 오래전에 ~했다". (我早就知道了(wǒ zǎo jiù zhīdào le))
- 还在(hái zài) + 장소/동작: "아직 ~에 있다, 아직 ~하는 중이다". (他还在睡觉(tā hái zài shuìjiào))

## [[중국어 Day 17]]

- 趁(chèn) + 상황: "~한 틈을 타서, ~할 때 (기회를 놓치지 않고)". 좋은 기회를 이용할 때 씀. (趁热吃(chèn rè chī), 趁年轻(chèn niánqīng))
- 好几(hǎo jǐ) + 양사: "여러, 꽤 많은". 几(jǐ)보다 수가 많다는 느낌을 강조함. (好几天(hǎo jǐ tiān), 好几次(hǎo jǐ cì))
- 省得(shěngde) + 원치 않는 일: "~하지 않도록, ~할 필요 없게". 미리 해 두는 이유를 뒤에 붙일 때 씀. 免得(miǎnde)와 비슷한 회화 표현. (早点儿走，省得堵车(zǎo diǎnr zǒu, shěngde dǔchē))
- 跑一趟(pǎo yí tàng): "한 번 다녀오다". 趟(tàng)은 오가는 횟수를 세는 양사. (去一趟超市(qù yí tàng chāoshì))
- 动不动就(dòngbudòng jiù) + 동사: "걸핏하면 ~하다, 툭하면 ~하다". 자주 일어나는 일(주로 좋지 않은 일)에 씀. (他动不动就生气(tā dòngbudòng jiù shēngqì))
- 犯困(fànkùn): "졸음이 오다, 졸리다". 犯(fàn)은 "(나쁜 상태가) 도지다"의 느낌. (一到下午就犯困(yí dào xiàwǔ jiù fànkùn))
- 说不定(shuōbudìng): "어쩌면 ~일지도 모른다". 估计(gūjì)보다 확신이 약한 추측. (说不定他忘了(shuōbudìng tā wàng le))
- 是因为(shì yīnwèi) + 이유: "~ 때문이다". 결과를 먼저 말하고 이유를 뒤에서 설명할 때 씀. (我迟到是因为堵车(wǒ chídào shì yīnwèi dǔchē))

## [[중국어 Day 18]]

- 难得(nándé): "모처럼, 좀처럼 없는". 자주 오지 않는 기회라 소중하다는 느낌. 문장 앞이나 명사 앞에 씀. (难得见一面(nándé jiàn yí miàn), 难得的好天气(nándé de hǎo tiānqì))
- 有个(yǒu ge) + 명사: 有一个(yǒu yí ge)에서 一(yī)를 뺀 회화체. 말할 때 아주 자주 생략함. (我有个问题(wǒ yǒu ge wèntí))
- 要不(yàobù) + 제안: "아니면 ~할까?, ~하는 게 어때?". 가볍게 제안할 때 문장 앞에 씀. 要不然(yàoburán)과 같은 뜻. (要不你先回去吧(yàobù nǐ xiān huíqu ba))
- 出去(chūqu) + 동사: "나가서 ~하다". 이동 동사 뒤에 목적이 되는 동작을 바로 이어 쓰는 연동문. (出去走走(chūqu zǒuzou), 回家吃饭(huí jiā chī fàn))
- 虽然(suīrán)……可(kě)……: "비록 ~지만, …". 회화에서는 但是(dànshì) 대신 可(kě)를 자주 씀. (虽然有点儿贵，可质量很好(suīrán yǒudiǎnr guì, kě zhìliàng hěn hǎo))
- 舍不得(shěbude) + 동사: "아까워서(아쉬워서) ~하지 못하다". 반대는 舍得(shěde). (舍不得花钱(shěbude huā qián), 舍不得走(shěbude zǒu))
- 毕竟(bìjìng): "어쨌든, 아무래도 (~이니까)". 앞에서 말한 감정·행동의 이유가 되는 사실을 강조함. (他毕竟还是个孩子(tā bìjìng hái shì ge háizi))
- 是(shì)……的(de): 이미 일어난 일에서 누가·언제·어떻게 했는지를 강조. 여기서는 '엄마가' 준 것임을 강조. (这是我自己做的(zhè shì wǒ zìjǐ zuò de))
- 双(shuāng): 신발·양말·젓가락처럼 짝을 이루는 것을 세는 양사. (一双袜子(yì shuāng wàzi))

## [[중국어 Day 19]]

- 好不容易(hǎo bù róngyì) + 동사: "간신히, 어렵게 겨우 ~하다". 부정 不(bù)가 있지만 뜻은 긍정이고, 好容易(hǎo róngyì)와 같은 뜻. (好不容易找到工作(hǎo bù róngyì zhǎodào gōngzuò), 好不容易等到周末(hǎo bù róngyì děngdào zhōumò))
- 동사 + 到(dào): 결과보어로 "(목표를) 손에 넣다, 해내다". 抢到(qiǎngdào)는 '경쟁해서 따내다', 티켓팅·한정판에 자주 씀. (买到(mǎidào), 找到(zhǎodào))
- 可(kě) + 千万(qiānwàn) + 别(bié) + 동사: "제발 절대 ~하지 마". 可(kě)는 어기를 강하게 하는 부사. (你可千万别告诉他(nǐ kě qiānwàn bié gàosu tā))
- 放(fàng) + 사람 + 鸽子(gēzi): "~를 바람맞히다, 약속을 펑크 내다". 사람이 放(fàng)과 鸽子(gēzi) 사이에 들어감. (他又放我鸽子了(tā yòu fàng wǒ gēzi le))
- 不是(bú shì) A 就是(jiù shì) B: "A 아니면 B". 둘 중 하나가 늘 반복된다는 뜻으로, 불평할 때 자주 씀. (他不是在睡觉就是在玩手机(tā bú shì zài shuìjiào jiù shì zài wán shǒujī))
- 反正(fǎnzhèng): "어차피, 어쨌든". 상황이 어떻든 결론은 같다는 느낌. (反正没事，我陪你去吧(fǎnzhèng méi shì, wǒ péi nǐ qù ba))
- 동사 + 不了(bu liǎo): 가능보어 "~할 수 없다". 상황·조건 때문에 못 하는 경우에 씀. (吃不了(chī bu liǎo), 去不了(qù bu liǎo))
- 还不如(hái bùrú) + 동사: "차라리 ~하는 게 낫다". 앞에서 말한 상황보다 이쪽이 낫다는 판단. (打车还不如坐地铁(dǎ chē hái bùrú zuò dìtiě))

## [[중국어 심화 문장]]

- 鉴于(jiànyú) + 상황: "~을 감안하여", 因为(yīnwèi)보다 격식 있는 표현.
- 就(jiù) + 대상: "~에 관하여". (就此事进行讨论(jiù cǐ shì jìnxíng tǎolùn))
- 予以(yǔyǐ) + 2음절 동사: "~을 해 주다"의 서면어. (予以确认(yǔyǐ quèrèn), 予以支持(yǔyǐ zhīchí))
- 如(rú) + 조건: 如果(rúguǒ)의 서면어.
- 贵司(guìsī) / 我方(wǒfāng): "귀사" / "당사".
- 上述(shàngshù): "상술한, 위에서 언급한". (上述条款(shàngshù tiáokuǎn))
- 敬请(jìngqǐng) + 동사: "~해 주시기 바랍니다", 请(qǐng)보다 공손한 표현.
