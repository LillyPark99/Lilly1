# 중국어 심화 문장

> 원본 문서에서 자동으로 만든 페이지입니다. 내용은 원본에서 고치면 다음 동기화 때 반영됩니다.

- 원본 제목: 심화 문장 (공문체)

## 鉴于双方长期合作的良好关系，我方愿意就手续费标准予以适当调整。

- 병음: Jiànyú shuāngfāng chángqī hézuò de liánghǎo guānxì, wǒfāng yuànyì jiù shǒuxùfèi biāozhǔn yǔyǐ shìdàng tiáozhěng.
- 뜻: 양사 간 장기적인 협력 관계를 고려하여, 당사는 수수료 기준을 적절히 조정할 의향이 있습니다.
- 문법:
    - 鉴于(jiànyú) + 상황: "~을 감안하여", 因为(yīnwèi)보다 격식 있는 표현.
    - 就(jiù) + 대상: "~에 관하여". (就此事进行讨论(jiù cǐ shì jìnxíng tǎolùn))
    - 予以(yǔyǐ) + 2음절 동사: "~을 해 주다"의 서면어. (予以确认(yǔyǐ quèrèn), 予以支持(yǔyǐ zhīchí))

## 如贵司对上述内容有任何疑问，敬请随时与我们联系。

- 병음: Rú guìsī duì shàngshù nèiróng yǒu rènhé yíwèn, jìngqǐng suíshí yǔ wǒmen liánxì.
- 뜻: 귀사에서 상기 내용에 대해 궁금한 점이 있으시면, 언제든지 연락 주시기 바랍니다.
- 문법:
    - 如(rú) + 조건: 如果(rúguǒ)의 서면어.
    - 贵司(guìsī) / 我方(wǒfāng): "귀사" / "당사".
    - 上述(shàngshù): "상술한, 위에서 언급한". (上述条款(shàngshù tiáokuǎn))
    - 敬请(jìngqǐng) + 동사: "~해 주시기 바랍니다", 请(qǐng)보다 공손한 표현.

## 주요 단어

| 단어 | 병음 | 뜻 |
|---|---|---|
| 鉴于 | jiànyú | ~을 감안하여 |
| 双方 | shuāngfāng | 양측, 쌍방 |
| 合作 | hézuò | 협력, 합작 |
| 手续费 | shǒuxùfèi | 수수료 |
| 予以 | yǔyǐ | ~을 해 주다 (서면어) |
| 适当 | shìdàng | 적절하다 |
| 调整 | tiáozhěng | 조정하다 |
| 贵司 | guìsī | 귀사 |
| 上述 | shàngshù | 상술한, 상기의 |
| 疑问 | yíwèn | 의문, 궁금한 점 |
| 敬请 | jìngqǐng | ~해 주시기 바랍니다 |
| 联系 | liánxì | 연락하다 |
